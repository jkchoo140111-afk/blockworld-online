# BLOCKWORLD ONLINE

브라우저에서 실행하는 3D 블록 월드 멀티플레이 게임의 시작 프로젝트입니다.

## 실행 방법
1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 터미널을 엽니다.
3. `npm install`
4. `npm start`
5. 브라우저에서 `http://localhost:3000` 접속

## 온라인 접속
- 같은 컴퓨터에서 테스트할 때는 브라우저 탭을 여러 개 열면 됩니다.
- 다른 사람이 접속하려면 서버를 외부에서 접속 가능한 호스팅에 배포해야 합니다.
- 배포 플랫폼은 Node.js와 WebSocket 연결을 지원해야 합니다.
- 서버 주소를 공유하면 같은 월드에 접속합니다.

## 현재 포함된 기능
- Three.js 기반 1인칭 3D 블록 월드
- 지형 생성(평원과 언덕), 나무, 물
- WASD 이동, 마우스 시점, 점프
- 블록 파괴/설치 및 간단한 인벤토리
- WebSocket 실시간 플레이어 위치/닉네임 동기화
- 블록 변경 동기화 및 채팅
- 모바일용 터치 이동/점프/설치/파괴 버튼

## 아직 구현되지 않은 기능
- 계정/클라우드 저장, 월드 영구 저장
- 몬스터 AI, 전투, 체력/허기 실제 시스템
- 동굴/광물/제작대 UI와 실제 제작 레시피
- 청크 스트리밍, 서버 권한 검증 강화, 안티치트
- 모바일 터치 시점 회전 및 정교한 충돌/물리

이 프로젝트는 플레이 가능한 멀티플레이 기반 버전이며, 정식 마인크래프트의 모든 기능을 복제한 완성품은 아닙니다.
